## Manul56HW

A fork of the Pteron56 design, this time with a 3D printed sandwich mount plate. This is a handwired keyboard so no pcb will be provided, although I plan on making a PCB version in the future.

## Features 
- Ergonomic non-split Layout : 56-key custom layout
- Hand-wired matrix : Built without a traditional pcb, handsoldered.
- Rotary encoder : Has built in button functionality, ideal for volume control
- PETG Sandwich case : Swapped the standard acrylic case for a custom 3D printed case
- Refurbished : I bought 120 factory defective switches for right under $2.50 and manually fixed and tested them by hand
- XDA Profile blank keycaps
